马上

第一次这样试

  1. 先用假麦克风，喇叭关着。这一步不用接任何线。如果《小星星》的 14 个音一个个出现，每个旁边都有 Duet 配的音，说明板子和整条通路都是好的。
  2. 接好线以后，换成真麦克风，喇叭还是关着。对着麦克风唱或者哼，看“你”那一格跟不跟着变。
  3. 最后再勾上喇叭，音量先从 30 开始。

注意：麦克风也听得见板子自己的喇叭。队友自己的程序在放声音的时候会停下来不听，现场合唱做不到这一点。喇叭太响的话，板子可能把自己的声音当成你的。所以喇叭要离麦克风远一点，音量一开始要小。

板子的声音

从板子的麦克风录一段，存成片段；或者把一个片段放给板子的喇叭。两样都是实时的：录 8 秒就要等 8 秒。

现在板子的声音是替身（stand-in）：板子上还没接麦克风和喇叭。
“麦克风”发来的是固件里算好的《小星星》，和 Mac 上算的一个采样都不差；“喇叭”不出声，只数收到几帧、算校验和（checksum），用来证明放的就是发过去的。
